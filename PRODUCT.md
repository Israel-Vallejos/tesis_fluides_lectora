# Fluidez

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Profesionales que acompañan a niños con dificultades lectoras; los niños tienen un acceso independiente con PIN.

## Product Purpose

Sistema de tesis para acompañamiento lector. En esta fase se comparan prototipos de acceso, sin autenticación real.

## Operating Context

Windows, IIS local y VS Code. Vistas accesibles directamente en localhost/tesis-fluidez/VISTAS/.

## Capabilities and Constraints

HTML, CSS y JavaScript sin framework para el prototipo. Futuro sistema PHP por capas AJAX, CONFIG, MODELOS, PUBLIC y VISTAS, con MySQL y Whisper local. Nombres propios y comentarios en español; etiquetas básicas, sin SVG decorativo. No implementar el backend en esta fase. URL sin parámetros para forzar caché.

## Brand Commitments

Nombre Fluidez. Se conserva el login azul y blanco aprobado, con registro y acceso infantil independientes.

## Evidence on Hand

VISTAS/login.html, VISTAS/registro.html, VISTAS/login_nino.html y .interface-design/system.md. Cuenta de demostración profesional@fluidez.com, contraseña 123456. No hay cuentas reales guardadas por estos prototipos.

## Product Principles

- Código entendible para un estudiante y organización por capas.
- Inicio de sesión y registro claros, accesibles por teclado y en móvil.
- Animaciones suaves con alternativa para movimiento reducido.
- No inventar testimonios, resultados ni servicios de autenticación.
